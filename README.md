# GenAI Practical 03 – Sequence Modeling using RNN and LSTM

This repository contains the implementation of sequence modeling techniques using Recurrent Neural Networks (RNNs) and Long Short-Term Memory (LSTM) networks in Python. The notebook demonstrates a simple RNN implementation, explores the limitations of standard recurrent architectures, and uses LSTM networks to handle long-term dependencies in sequential data. It also demonstrates language modeling using text sequences and evaluates sequence models using relevant performance measures.
